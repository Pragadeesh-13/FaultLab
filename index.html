menu_book What Is This Project?

FaultLab is an educational tool that simulates laser fault injection (LFI) attacks against public-key cryptosystems. In real hardware, an attacker can use a focused laser beam to flip individual transistor bits on a silicon die during computation. This project visualizes that process and shows — at the bit level — how the math breaks down.

flowchart How The Simulation Works

1
Enter Plaintext

Type a message like "HELLO" or a number like 123. This is encrypted using both ElGamal and Cramer-Shoup with identical 8-bit parameters (p = 227).

2
Inject a Fault

Click the silicon die to fire a laser, or click the oscilloscope to inject a voltage glitch. This flips a random bit in the ciphertext during decryption.

3
Compare Results

Watch the side-by-side 8-bit calculation trace. ElGamal silently outputs a corrupted byte. Cramer-Shoup detects the mismatch (v != v') and aborts.

security Why ElGamal Fails and How Cramer-Shoup Prevents It

warning
ElGamal: Why It Fails
Like sending a secret letter in an unsealed envelope
1
Message is hidden, but never checked

ElGamal scrambles your secret message so eavesdroppers cannot read it. But it never attaches any tamper seal or checksum to verify if anyone altered the data.

2
A laser flips a single bit in the chip

During decryption, an attacker hits the chip with a laser pulse or power glitch. This flips a single 0 into a 1 inside the chip's memory.

3
The chip blindly unlocks the corrupted data

Because ElGamal has no built-in verification, the chip doesn't know anything is wrong. It blindly completes the math on the altered bits.

4
Silent failure — corrupted output accepted

The system spits out corrupted text or wrong numbers without any warning or error. The receiver trusts it blindly, and the attacker wins without ever cracking the private key.

dangerous Result: Tampered data accepted blindly (0% detection)
shield
Cramer-Shoup: How It Prevents It
Like a security lockbox with a tamper-evident wax seal
1
Message is locked with a security seal

Cramer-Shoup encrypts the message and attaches a unique mathematical "proof tag" (a digital seal) that binds all parts of the ciphertext together.

2
The laser flips a bit in the chip

The attacker targets the hardware with the exact same laser fault, changing a bit in memory during the decryption process.

3
The security seal breaks immediately

Before opening the message, the chip recalculates what the seal should look like. Because even a single bit changed, the seal no longer matches.

4
Instant abort — attack completely blocked

The chip catches the mismatch, sounds an alarm, and immediately stops decryption. It wipes the data and refuses to output corrupted plaintext, keeping the system safe.

verified_user Result: Tampering detected and blocked instantly (100% detection)
